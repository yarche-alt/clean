# Чистка — нативное приложение для iPhone

Приложение находит в галерее скриншоты карточек товаров Ozon, Wildberries и Яндекс Маркета
и удаляет их одним тапом. Переписки, документы, чеки и заметки остаются нетронутыми.

**Как работает:**
- `PhotoKit` — забирает всё из системного альбома «Снимки экрана»;
- `Vision` (OCR, русский + английский) — распознаёт текст прямо на устройстве, ничего не отправляется в сеть;
- Эвристический классификатор (`Classifier.swift`): ищет фразы «в корзину», «купить», «ozon», «wildberries», «пункт выдачи», цены со знаком ₽ и т.п. Порог срабатывания легко настроить (`junkThreshold`);
- Удаление — через `PHAssetChangeRequest.deleteAssets`: iOS **показывает системное подтверждение**, а файлы попадают в «Недавно удалённые» на 30 дней (оттуда всё можно вернуть).

## Сборка: три пути

### Путь A. У вас есть Mac (самый простой, установка по кабелю)

1. Установите Xcode 16+ и XcodeGen (`brew install xcodegen`).
2. В папке проекта выполните `xcodegen generate` — появится `CleanShots.xcodeproj`.
3. Откройте проект. В target **CleanShots → Signing & Capabilities** выберите свою команду
   (Personal Team с бесплатным Apple ID подходит).
4. Подключите iPhone кабелем, разблокируйте его, выберите его в списке устройств и нажмите **Run**.
5. На iPhone: **Настройки → Основные → VPN и управление устройством → доверять разработчику**.
   Если iOS попросит — включите **Режим разработчика** (Настройки → Конфиденциальность и безопасность).

> Бесплатный Apple ID: приложение работает 7 дней, затем просто нажмите Run ещё раз (или пересоберите). С платной учёткой ($99/год) — без ограничений.

### Путь B. Mac нет — сборка в облаке (GitHub Actions) + установка с Windows/Mac через Sideloadly

1. Создайте на GitHub приватный репозиторий и загрузите в его корень содержимое этой папки
   (так, чтобы `project.yml`, папка `CleanShots` и папка `.github` лежали в корне).
2. Вкладка **Actions** → workflow «Сборка CleanShots.ipa» → **Run workflow**.
   Через ~5–10 минут в завершённом запуске скачайте артефакт **CleanShots-ipa**.
3. Установите на компьютер [Sideloadly](https://sideloadly.io) (работает на Windows и macOS;
   для Windows дополнительно нужны iTunes и iCloud **не из Microsoft Store**).
4. Подключите iPhone кабелем → в Sideloadly выберите `CleanShots.ipa`, введите свой Apple ID → **Start**.
   Sideloadly сам подпишет приложение вашим сертификатом и установит его.
5. На iPhone: доверить сертификату (Настройки → Основные → VPN и управление устройством)
   и при необходимости включить Режим разработчика.

> Бесплатный сертификат действует 7 дней — продлевайте тем же Sideloadly, настройки приложения сохранятся. Лимит: 3 приложения одновременно (лимит Apple для бесплатных аккаунтов).

### Путь C. Платный аккаунт разработчика

Архивируйте в Xcode (**Product → Archive**) и раздайте через TestFlight или Ad Hoc — приложение не будет истекать каждые 7 дней.

## Структура кода

| Файл | Назначение |
| --- | --- |
| `CleanShots/CleanShotsApp.swift` | Точка входа |
| `CleanShots/Models.swift` | Модели: скриншот, вердикт, экраны |
| `CleanShots/PhotoLibrary.swift` | PhotoKit: доступ, скриншоты, миниатюры, удаление |
| `CleanShots/Classifier.swift` | Vision OCR + эвристика «мусор / важное» |
| `CleanShots/RootView.swift` | Весь UI: сканирование, результаты, свайп-проверка, успех |
| `project.yml` | Спецификация для XcodeGen |
| `.github/workflows/build-ipa.yml` | Облачная сборка .ipa |

## Тонкая настройка

- Словарь маркеров — массив `junkTerms` в `Classifier.swift`. Хотите строже — поднимите `junkThreshold` с 3 до 4–5.
- Приложение анализирует только альбом «Снимки экрана»; обычные фото не трогаются.
- Доступ к фото — «Полный». При «Ограниченном» будут обработаны только выбранные вами фото.
